# Logo

The twise brand: the two-eyed owl and the lowercase name, always together in the full logo.

**Versions (asset group `Logo`)**
- `twise-logo.svg`: full logo (icon + name) for light backgrounds. `twise-logo-claro.svg`: the same for dark backgrounds.
- `twise-icone.svg`: the app icon (owl on the mint square). It is also the social media avatar.
- `twise-coruja.svg`: the owl with no background, for use as a mascot (welcome, empty screens) on `sketch-paper` or `mint-soft`.
- `twise-logotipo.svg` / `twise-logotipo-claro.svg`: the name only, for when the icon already appears nearby.

**Rules**
- Clear space: half the icon's width around the logo, with no text or border inside it.
- Minimum size: icon at 24px; full logo at 96px wide.
- The name is always "twise" in lowercase, all letters the same size, in Bricolage Grotesque 750. In running text, "Twise" with a capital initial.
- Do not:
  - change the eye colors;
  - place the owl on red or on busy photos;
  - stretch, rotate or outline the logo;
  - recreate the name in another font.

**What the team provides:** use the SVG files as they are (`<img>`). For the PWA, generate the icon PNGs (192 and 512px) from `twise-icone.svg`.

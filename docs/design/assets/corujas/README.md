# Owl scenes (`corujas`)

The owl scenes for the account screens and the moments, ready for `<img>`.

- Same base in all of them: owl, coins, plant, cream background.
- One object that changes:
  - welcome (sparkle)
  - waiting (hourglass)
  - email (envelope)
  - no connection (cloud)
  - sign-up (form card)
  - confirmed (check)
  - key
  - expired link (chain)
  - closed (padlock)
  - invite (card)
  - together (the two owls, with mirrored eyes: the two mint eyes meet in the middle)
- Always on `mint` or `sketch-paper`.
- To animate, use the version from the **Corujas em camadas** group and the entrances in **States and motion → Owl motion** in the design-system README (`docs/design/design-system/README.md`).
